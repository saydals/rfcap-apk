# RF Rebuilt with Capacitor

RF has been rebuilt using Capacitor, providing a modern cross-platform mobile experience.

## New Adjustment Tab Feature

The original Adjustment tab required 10+ clicks from scratch — too complex and overwhelming. We simplified the most commonly used tuning items for faster, more intuitive operation.

**How to use:**
1. Select the desired feature
2. Move your transmitter's assigned switch (or set it manually)
3. That's it — Aux assignment is complete

When you tap **Select**, the Aux item defaults to **Auto** and automatically detects the transmitter key you moved. You can also tap for manual setup. After saving, moving the 3-position switch adjusts that item's value in real time:

- **Middle position:** no change
- **Up:** value increases
- **Down:** value decreases

Step size defaults to 1, with the value changing approximately 5–10 steps per second. In practice, adjust for 1–3 seconds, then return the 3-position switch to the middle and observe the helicopter's response.

This simplified feature occupies **Adjustment slots 5–17**; slots 1–4 remain available for any other functions you want to assign.
